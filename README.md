# coconutbird/.github

This repository holds the default community health files for repositories that `coconutbird` owns.
GitHub shows each file on every `coconutbird` repository that does not have its own file of that type.

| File | Purpose |
| --- | --- |
| [`SECURITY.md`](SECURITY.md) | The security policy and the procedure to report a vulnerability. |

## Keep this repository public

GitHub uses default files only from a public `.github` repository.
If this repository becomes private, every `coconutbird` repository loses its security policy.

## Private vulnerability reporting

These repositories have private vulnerability reporting enabled:

- `ww2ogg-rs`
- `nostdio`
- `d3dasm`
- `clrmeta`
- `.github`

The form in this repository receives reports for every other repository.
Do not disable private vulnerability reporting on this repository.
